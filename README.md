## About

AURUM is a modern luxury jewelry e-commerce platform built with React and Node.js. It features immersive 3D product showcases powered by Three.js, a sophisticated gold-themed design system, and a responsive shopping experience optimized for luxury retail.

## Features

- **3D Product Showcases** - Interactive product visualization using Three.js
- **Gold-Themed Design System** - Elegant, luxury-focused styling
- **Responsive Shopping Experience** - Mobile-optimized for all devices
- **Virtual Showroom** - Immersive brand experience
- **AI Stylist** - Personalized jewelry recommendations

## Development

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0

### Frontend

```sh
cd frontend
npm install
npm run dev
```

### Backend

```sh
cd backend
npm install
npm run dev
```
